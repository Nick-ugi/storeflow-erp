| 항목 | 내용 |
|---|---|
| 문서 버전 | v1.0 |
| 작성일 | 2026-09-25 |
| 상태 | 확정 |
| 기준 문서 | [요구사항 정의서 v1.0](01-requirements.md) |

> 이 문서는 시스템의 **화면 구성, 메뉴 구조, 화면과 요구사항의 연결**을 정의한다.
> 화면별 입력 항목 · 검증 규칙 · 처리 로직은 ③ 상세 기능 명세에서 정의한다.

---

## 1. 화면 ID 규칙

- 형식: `SCR-{업무코드}-{번호}` (예: `SCR-SALE-001`)
- 업무코드는 요구사항 정의서와 동일하며, 화면 전용으로 `COM`(공통)을 추가한다.
- **유형**
  - `화면`: URL을 가진 독립 페이지
  - `팝업`: 다른 화면 위에 뜨는 모달 (URL 없음)
  - `공통`: 모든 화면에 포함되는 영역
- **URL**은 React Router 경로로 그대로 사용한다.

---

## 2. 메뉴 구조

```
StoreFlow ERP                           ADMIN  MANAGER  USER
├── Dashboard                             O       O       O
├── 판매
│   ├── 판매 등록                          O       O       O
│   └── 판매 내역                          O       O       O
├── 재고
│   ├── 현재 재고                          O       O       O
│   └── 재고 이력                          O       O       O
├── 발주
│   └── 발주 목록                          O       O       X
├── 기준정보
│   ├── 상품                               O       O       O
│   ├── 카테고리                           O       O       O
│   └── 공급처                             O       O       O
└── 시스템 관리
    ├── 매장 관리                          O       X       X
    └── 사용자 관리                        O       X       X
```

- 상세 · 등록 · 수정 화면은 메뉴에 두지 않고 목록 화면의 버튼이나 행 클릭으로 이동한다.
- 기준정보(상품 · 카테고리 · 공급처)는 전 역할이 조회할 수 있고, 등록 · 수정 버튼은 ADMIN에게만 보인다.

## 3. 화면 공통 규칙

| # | 규칙 |
|---|---|
| 1 | 로그인하지 않은 상태로 접근하거나 인증 토큰이 만료되면 로그인 화면으로 이동한다. |
| 2 | 로그인 후 첫 화면은 Dashboard다. (`/` 접속 시 `/dashboard`로 이동) |
| 3 | 권한이 없는 메뉴와 버튼은 표시하지 않는다. URL로 직접 접근하면 권한 없음 화면을 보여준다. (서버에서도 별도로 검사한다: BR-003) |
| 4 | **ADMIN 매장 선택**: 목록 · 조회 화면은 검색 조건에 '매장'이 추가된다. (기본값: 전체) 판매 등록 · 발주 등록 화면은 '매장'을 반드시 선택해야 한다. |
| 5 | **MANAGER · USER**는 매장 조건 없이 소속 매장 데이터만 표시된다. |
| 6 | 목록 화면은 `검색 영역 + 결과 표 + 페이지 이동`으로 구성하며, 한 페이지에 20건을 표시한다. |
| 7 | 판매 취소, 발주 승인 · 입고 · 취소, 사용 중지 · 비활성화처럼 상태를 바꾸는 작업은 확인 대화상자를 거친 뒤 실행한다. |
| 8 | 금액은 천 단위 구분 기호와 '원'을 붙여 표시한다. 날짜는 `YYYY-MM-DD`, 일시는 `YYYY-MM-DD HH:mm` 형식이다. |

## 5. 주요 화면 흐름

```
[판매]
판매 등록 ──(상품 선택 팝업)──▶ 판매 완료 ──▶ 판매 상세
판매 내역 ──▶ 판매 상세 ──(판매 취소)──▶ 상태 '취소'

[발주]
발주 목록 ──(발주 등록)──▶ 발주 등록 ──(저장)──▶ 발주 상세
발주 상세  '작성' ──(승인)──▶ '승인' ──(입고)──▶ '입고완료'
             │                 │
             ├─(수정)──▶ 발주 수정
             └─(취소)──▶ '취소' ◀──(취소)─┘

[재고]
현재 재고 ──▶ 재고 상세 ──▶ 재고 조정 팝업 / 안전재고 설정 팝업
재고 이력 ──(관련 번호)──▶ 판매 상세 / 발주 상세

[Dashboard]
재고 부족 상품 ──▶ 현재 재고 ('부족 재고만 보기' 적용)
최근 판매      ──▶ 판매 상세
최근 발주      ──▶ 발주 상세
```
